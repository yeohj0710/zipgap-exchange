# data/listings.json 규격

거래소가 읽는 유일한 시세 원장이다. 이 파일만 바꾸면 사이트 값이 바뀐다.
코드는 건드리지 않는다.

## 전체 모양

```json
{
  "version": "2026-08-13",
  "status": "seed-estimate | partial-real | real",
  "note": "데이터 상태를 한 줄로 적는다",
  "assets": [ /* 종목 배열 */ ]
}
```

| 필드 | 뜻 |
| --- | --- |
| `version` | 데이터를 마지막으로 손댄 날. `YYYY-MM-DD` |
| `status` | `real` 은 모든 종목의 최근 12개월이 실거래 원자료일 때만 쓴다 |
| `note` | 사이트 배너에 그대로 나가지는 않지만, 사람이 읽는 상태 메모다 |

## 종목 하나

```json
{
  "symbol": "EUNMA",
  "name": "은마아파트",
  "alias": "은마",
  "kind": "complex",
  "sido": "서울",
  "region": "서울 강남구 대치동",
  "unitArea": 84.43,
  "households": 4424,
  "builtYear": 1979,
  "tags": ["재건축", "학군"],
  "rentYield": 0.014,
  "shareDivisor": 100000,
  "lawdCd": "11680",
  "aptName": "은마",
  "history": [
    { "ym": "2026-07", "price": 282500, "trades": 12, "source": "real" }
  ]
}
```

| 필드 | 필수 | 규칙 |
| --- | --- | --- |
| `symbol` | O | 대문자 영문·숫자만. 한 번 정하면 바꾸지 않는다. 바꾸면 사람들 보유 종목이 끊긴다 |
| `name` | O | 화면에 나오는 이름 |
| `alias` | | 검색용 짧은 별칭 |
| `kind` | O | `complex`(단지) 또는 `index`(지수) |
| `sido` | O | `서울` `경기` `인천` `부산` `전국` `광역시` 중 하나. 새 값을 쓰려면 `components/market-table.tsx` 의 `SIDOS` 도 같이 늘린다 |
| `region` | O | 사람이 읽는 위치. 단지는 시군구 읍면동까지 |
| `unitArea` | 단지만 | 대표 전용면적 m². 실거래를 고를 때 이 면적 ±1.5m² 안만 쓴다 |
| `households` | | 세대수 |
| `builtYear` | | 준공 연도 |
| `tags` | O | 빈 배열이라도 넣는다 |
| `rentYield` | O | 연 임대수익률. 0.01 = 1%. 월세 배당 계산에 쓴다 |
| `shareDivisor` | O | 한 채를 몇 조각으로 쪼갰는지. **항상 100000** 으로 둔다 |
| `lawdCd` | 단지만 | 법정동코드 앞 5자리(시군구). 실거래 조회 열쇠 |
| `aptName` | 단지만 | 국토부 자료에 적힌 아파트명 원문. `name` 과 다를 수 있다 |
| `history` | O | 월별 시세. `ym` 오름차순, 빠진 달 없이 이어져야 한다 |

## history 한 줄

| 필드 | 규칙 |
| --- | --- |
| `ym` | `YYYY-MM`. 앞뒤 달과 정확히 한 달씩 차이 나야 한다 |
| `price` | **만원 단위**. 27억이면 `270000`. 소수점 없는 정수 |
| `trades` | 그 달 거래 건수. 모르면 넣지 않는다 |
| `source` | `real` 은 실거래 원자료로 계산한 값일 때만. 추정치는 `seed` |

### price 를 정하는 방법

단지형은 그 달 실거래 중 **전용면적이 `unitArea` ± 1.5m² 안인 건들의 중앙값**을 쓴다.
평균이 아니라 중앙값이다. 한 건이 값을 끌고 가는 일을 막는다.

- 그 달 거래가 **1건도 없으면** 앞뒤 달을 로그 선형으로 이어 채우고 `source: "seed"` 로 둔다.
- 거래가 1~2건뿐이면 그대로 쓰되 `trades` 를 정확히 적는다.
- 층·향 보정은 하지 않는다. 중앙값으로 충분하다.

지수형은 구성 지역 전체 아파트 거래의 중앙값을 같은 방식으로 낸다.

## 절대 하면 안 되는 것

1. **`symbol` 을 바꾸거나 지우지 않는다.** 사람들이 그 종목을 이미 갖고 있다.
   이름이 틀렸으면 `name` 만 고친다.
2. **`shareDivisor` 를 바꾸지 않는다.** 바꾸면 모든 사람의 평가액이 한순간에 튄다.
3. **지난 달 `price` 를 소급해서 고치지 않는다.** 이미 그 값으로 거래가 일어났다.
   원자료가 나중에 정정되면 최근 3개월 안에서만 고친다.
4. **추정치에 `source: "real"` 을 붙이지 않는다.** 이 표시가 화면의 "표본값" 배너를 끈다.
